# AI-чат банковского приложения на локальной модели

[![hexlet-check](https://github.com/Obolduy/test-program-please-ignore-llm-lvl2-project-455/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/Obolduy/test-program-please-ignore-llm-lvl2-project-455/actions)

Переведите готовый агентный чат банка с облачной модели на локальную и управляйте модельным слоем как продуктом. Вы подключите локальный сервер модели к пулу провайдеров и замерите его, соберёте eval-батарею с порогами от облачного baseline и доведёте локаль до зелёного гейта. Затем выпустите версию с чексуммой и откатом, добавите маршрутизацию запросов и маскирование персональных данных, соберёте гибрид с деградацией при отказе провайдера и посчитаете стоимость диалога и точку окупаемости.

Учебный проект Хекслета: https://ru.hexlet.io/programs/test-program-please-ignore-llm-lvl2
